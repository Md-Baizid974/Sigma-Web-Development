Variables, Data Types & Objects

What is Variables?

A Variable is a container that stores a value. This is very similar to the container used to store rice, wate, & oats.

JavaScirpt variables can be declared in 4 ways:

  • Using let
  • Using const
  • Using var (Not Recomended)
  • Automatically (Not Recomended)

Rules for using variables name

  • Names can contain letters, digits, underscores, and dollar signs.
  • Names must begin with a letter, a $ sign or an underscore ( _ ).
  • Names are case sensitive (X is different form x).
  • Reserved words (JavaScirpt keywords) cannot be used as names.

Var VS Let Vs Const

  1. Var is globally scoped while let & const are block scoped.
  2. Var can be updated & re-declared within its scope
  3. Let can be update but not re-declared.
  4. Const can neither updated nor be re-declared.
  5. Var variables are initialized with undefined whereas let & const variables are not initialized.
  6. Const must be initialized during unlike let and var
